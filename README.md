# Rock Paper Scissors 

An interactive Python terminal-based Rock Paper Scissors game featuring live scorekeeping, input validation, and clean formatting. when ur writing code for looooooong and wanna take break and get back lock in , Tryyy playing game on terminallllllll

## Features

* terminal gameplay against an bot opponent
* score tracking for player wins, computer wins, and ties
* input validation so it doesnt crash if u type something random
* final scoreboard when u quit the game

## How to Run

### Prerequisites

* Python 3 installed on ur machine

### Running the Game

1. clone the repo:
git clone [https://github.com/batman990-bit/ROCK-PAPER-SCISSORS.git](https://www.google.com/search?q=https://github.com/batman990-bit/ROCK-PAPER-SCISSORS.git)
2. go into the folder:
cd ROCK-PAPER-SCISSORS
3. run the script:
python3 main.py

## Code Overview

main.py uses pythons random module to generate choices for the bot. user inputs are normalized so case sensitive stuff doesnt break it, and simple control flow tracks the score until u type quit.
